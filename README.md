# 摩旅 App：ESP32 原型计划

我想做一款面向摩托车爱好者的 App，用来分享骑行路线、旅途见闻和实用经验。

首版计划用带串口的 OBD 模块读取 Honda CB500X 的转速，再由 ESP32 通过蓝牙发到安卓手机。ESP32 不直接接摩托车的诊断口。先验证两件事：手机能否稳定读到真实转速，以及蓝牙断开后能否重新连接。原型只读取数据，不改车辆设置。

另一个待验证的想法是：山里没有移动网络时，让同行骑友连接同一个便携 Wi‑Fi，在局域网里按键对讲。这个方案仍受 Wi‑Fi 覆盖限制，不是应急通信的替代品。

**当前状态：这是公开的原型计划，尚无实车或野外测试结果。**

项目记录：#DevinBots

## 运行转速读取示例（不需要开发板）

在仓库目录运行以下命令，只需要 Python 3：

```sh
python3 obd_rpm.py
python3 -m unittest -v
```

示例先发 `0100`，确认车辆声明支持转速，再发 `010C`。例如模拟回包 `41 0C 1A F8` 会换算成 `1726 RPM`。如果车辆不支持，就不发转速请求；如果没有有效回包，就报错，不沿用上一次的读数。

这里验证的是标准 OBD-II 读取顺序和数据解析。示例只接收模拟回包，不连接车辆，也不包含 ESP32 固件或安卓蓝牙代码。CB500X 是否实际返回这些数据，仍需上车确认。接硬件时应由串口层拼齐整条回包（直到 `>`），并设置读取超时。
